# Coderama

Coderama is a desktop app for building things with AI: chat with Claude or other models, let them read and change your project files, check websites in a built-in browser, and undo anything with one click.

This repository only holds the **installers and update files**. There is no source code here.

## Download

Go to **[Releases](https://github.com/matixacik-cell/coderama-releases/releases/latest)** and download:

- **Mac (Apple Silicon):** [Coderama-0.1.0-arm64.dmg](https://github.com/matixacik-cell/coderama-releases/releases/latest/download/Coderama-0.1.0-arm64.dmg)
- **Windows:** [Coderama-Setup-0.1.0.exe](https://github.com/matixacik-cell/coderama-releases/releases/latest/download/Coderama-Setup-0.1.0.exe)

(Newer versions have the new number in the file name; the Releases page always has the latest.)

## First open

- **Mac:** open the dmg and drag Coderama to Applications. The first time, right-click Coderama in Applications, choose **Open**, then **Open** again.
- **Windows:** if you see "Windows protected your PC", click **More info**, then **Run anyway**.

On first launch Coderama asks how it should think: sign in with your own **Claude Code**, or paste your own **API key** (Anthropic, OpenAI, DeepSeek, OpenRouter, Google...). Your keys stay on your computer.

## Updates

Coderama updates itself. When a new version is ready you'll see **"Restart to update"** at the bottom of the window.
